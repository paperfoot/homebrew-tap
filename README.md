# paperfoot/homebrew-tap

Homebrew formulas for [paperfoot](https://github.com/paperfoot) CLIs.

## Usage

```bash
brew tap paperfoot/tap
brew install email-cli
brew install gemtts
brew install paperfoot/tap/stamp-cli
```

## Formulas

- [`email-cli`](Formula/email-cli.rb) — agent-friendly email CLI for Resend
- [`gemtts`](Formula/gemtts.rb) — agent-friendly Gemini TTS CLI for expressive scripts, voices, tags, and audio files
- [`stamp-cli`](Formula/stamp-cli.rb) — signature graphics, bilingual company seals, and office stamps in PNG and SVG
